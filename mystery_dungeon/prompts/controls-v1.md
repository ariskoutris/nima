# General controls

From the [Red Rescue Team instruction booklet](https://www.nintendo.com/eu/media/downloads/games_8/emanuals/game_boy_advance_8/Manual_GameBoyAdvance_PokemonMysteryDungeonRedRescueTeam_EN.pdf), pages 8–9. These rules describe the controls, not the current objective or map.

- The directional pad moves the character in the field and dungeons. In a menu it moves the cursor.
- A selects or confirms a command. In a dungeon it makes a regular attack or talks to the Pokémon you face. Use A to interact with a nearby object or character and to advance text when prompted.
- B opens the menu during play or cancels a command. Holding B while using the directional pad runs.
- START does nothing in the field; in a dungeon it changes the direction you face while standing still. SELECT displays the dungeon map.
- Choose an action for the visible situation: movement to approach a target, A when facing an interactable target, and directional pad then A for a menu choice.
